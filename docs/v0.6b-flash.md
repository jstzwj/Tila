## 1. 目标程序

### 1.1 `flash.tila`：v0.6b 的正式验收程序（inline softmax，任意 N）

与 `docs/v0.6-attention.md` §1.2 逐行一致，两处对齐升级（评审焦点 #2）：

```python
import tila


@tila.jit
def flash(
    q: tila.Tensor[tila.float16, M, D],
    k: tila.Tensor[tila.float16, N, D],
    v: tila.Tensor[tila.float16, N, D],
    o: tila.Tensor[tila.float16, M, D],
    BM: tila.constexpr = 64,
    BN: tila.constexpr = 64,
    BD: tila.constexpr = 64,
):
    pid = tila.program_id(0)
    rm2 = tila.expand_dim(pid * BM + tila.arange(0, BM), 1)
    rn2 = tila.expand_dim(tila.arange(0, BN), 0)
    rn3 = tila.expand_dim(tila.arange(0, BN), 1)
    rd2 = tila.expand_dim(tila.arange(0, BD), 0)
    rd3 = tila.expand_dim(tila.arange(0, BD), 1)
    q2 = tila.load(q, (rm2, rd2), mask=(rm2 < M) & (rd2 < D), other=0.0)

    m = tila.full((BM,), tila.neg_inf, tila.float32)   # max 种子（零元）
    l = tila.zeros((BM,), tila.float32)                # sum 种子
    acc = tila.zeros((BM, BD), tila.float32)           # 输出累加种子
    for n0 in tila.range(0, N, BN):
        rkn = rn2 + n0
        rvn = rn3 + n0
        k2 = tila.load(k, (rkn, rd3), mask=(rkn < N) & (rd3 < D), other=0.0)
        v2 = tila.load(v, (rvn, rd2), mask=(rvn < N) & (rd2 < D), other=0.0)
        qk = tila.dot(q2, k2)
        qk_ = tila.where(rkn < N, qk, tila.neg_inf)     # R-PT：谓词不进布局代数
        rowmax = tila.max(qk_, axis=1)
        m1 = tila.maximum(m, rowmax)                    # StateRead（入口值）
        alpha = tila.exp2(m - m1)                       # 首迭代 e^{-inf-m1} = 0 ✓
        p = tila.exp2(qk_ - tila.expand_dim(m1, 1))     # Mma 派生闭包内（R-BT）
        l *= alpha                                      # ScaleUpdate
        l += tila.sum(p, axis=1)
        acc *= tila.expand_dim(alpha, 1)                # 跨 Mma rescale（R-ST）
        acc += tila.dot(tila.cast(p, tila.float16), v2)
        m = m1                                          # HandoffUpdate
    y = acc / tila.expand_dim(l, 1)                     # 终归一化（R-BT；循环后读合法）
    tila.store(o, (rm2, rd2), tila.cast(y, tila.float16), mask=(rm2 < M) & (rd2 < D))
```

对齐升级（本规划新增）：① `exp` → **`exp2`**（同 tutorial 数学——目的
是**消除两实现的刻意数学形态差**，不承诺逐 bit 同路径：libdevice 实现/
中间舍入/快速数学差异仍属差分容差，评审 B-③）；② **qk 缩放走 host 侧
预缩放 k**——`k_s = k * (sm_scale / ln 2)` 在 host 完成（tutorial 自己的
bwd 就是同款 `arg_k = arg_k * (sm_scale * RCP_LN2)` 技巧）。这是
**reference adaptation（参考适配）**：当前 surface **没有运行期 f32 标量
参数**（未注解参数 → `Scalar(i32)`），预缩放是 zero-new-surface 的适配，
**不暗示 Tila 已支持任意运行期 f32 标量**——该缺口显式记为 v0.7-A 表面
扩展（§5.1）。① ② 都只是既有规则的组合或 host 侧变换，非新设计。

**与教程实现的两处刻意差异（我们更强，均有测试背书，§4）**：掩码用
`-inf`（教程用 −1e6 加法哨兵——有限哨兵对合法大负 logits 可污染，v0.5
已否决同款；**语义鲁棒性对抗测试**专门验证，评审 B-⑯）；`l` 种子用 zeros
（教程初始 1.0 是历史冗余——`l₁ = 1·α₁ + l_ij = 0·α₁ + l_ij` 因 α₁ =
exp2(−∞−rowmax) = 0 恒等，**该恒等式作为 semantic identity test 固化**，
评审 B-⑰；且教程在全掩码首块有 α = exp2(NaN) 隐患，我们的 `where(-inf)`
+ N ≥ 1 构造杜绝）。

### 1.2 `attn_fwd.tila`：fused attention forward（与官方教程互证）

```python
import tila


@tila.jit
def attn_fwd(
    q: tila.Tensor[tila.float16, ZH_N, D],
    k: tila.Tensor[tila.float16, ZH_N, D],     # host 已预缩放 k_s = k * (sm_scale/ln2)
    v: tila.Tensor[tila.float16, ZH_N, D],
    o: tila.Tensor[tila.float16, ZH_N, D],
    BM: tila.constexpr = 64, BN: tila.constexpr = 64, BD: tila.constexpr = 64,
):
    pid = tila.program_id(0)
    rn = pid * BM + tila.arange(0, BM)             # 拍平行坐标（跨越 batch/head）
    rm2 = tila.expand_dim(rn, 1)
    rn2 = tila.expand_dim(tila.arange(0, BN), 0)   # N 方向（zh 内）
    rn3 = tila.expand_dim(tila.arange(0, BN), 1)
    rd2 = tila.expand_dim(tila.arange(0, BD), 0)
    rd3 = tila.expand_dim(tila.arange(0, BD), 1)
    rows = rn < ZH_N

    q2 = tila.load(q, (rm2, rd2), mask=rows & (rd2 < D), other=0.0)
    m = tila.full((BM,), tila.neg_inf, tila.float32)
    l = tila.zeros((BM,), tila.float32)
    acc = tila.zeros((BM, BD), tila.float32)
    for n0 in tila.range(0, N, BN):
        rkn = rn2 + n0
        rvn = rn3 + n0
        k2 = tila.load(k, (rkn, rd3), mask=(rkn < N) & (rd3 < D), other=0.0)
        v2 = tila.load(v, (rvn, rd2), mask=(rvn < N) & (rd2 < D), other=0.0)
        qk = tila.dot(q2, k2)                  # 缩放已由 host 预乘进 k
        cmask = (rm2 >= rkn)                   # 因果三角（步骤 2 前需 zh 内行号）
        qk_ = tila.where(cmask & (rkn < N), qk, tila.neg_inf)
        rowmax = tila.max(qk_, axis=1)
        m1 = tila.maximum(m, rowmax)
        alpha = tila.exp2(m - m1)
        p = tila.exp2(qk_ - tila.expand_dim(m1, 1))
        l *= alpha
        l += tila.sum(p, axis=1)
        acc *= tila.expand_dim(alpha, 1)
        acc += tila.dot(tila.cast(p, tila.float16), v2)
        m = m1
    y = acc / tila.expand_dim(l, 1)
    tila.store(o, (rm2, rd2), tila.cast(y, tila.float16), mask=rows & (rd2 < D))
```

- **拍平行坐标 = 全局行号**：`pid * BM + arange` 横跨 (z,h) 边界——**非因果
  不需要 zh 内行号**（列掩码 `rkn < N` 只看块内列），任意 N 正确；
- **因果需要 zh 内行号**（三角掩码 `i >= j` 的 i 是 zh 内行）：拍平单轴下
  块可能跨越序列边界。**causal acceptance condition（语义级，评审 B-①
  正式化）**：

  ```
  causal 变体的合法前提：flattened row tile 完整落在单个 (z,h) sequence 内
      ∀pid: ⌊pid·BM/N⌋ = ⌊(pid·BM + BM − 1)/N⌋
  充分条件（本实现采用）：N % BM == 0（N = k·BM 时左式 = ⌊pid/k⌋、右式 =
      ⌊(pid+1)/k − 1/(k·BM)⌋ = ⌊pid/k⌋——BM | N ⇒ 每序列恰 k 个整块，
      块不跨序列）
  执行：causal 变体的 launcher 携带 `N % BM == 0` 断言行（host 侧，模式
      同 RowMajor 连续断言）——不是仅测试包络；破除"经验约束"误用
  ```
  任意 N 的因果（`row % N` 需标量 `%`）→ v0.7-A（§5.1）一并裁定。
- **causal 是编译期语义特化**：当前 Tila 无 constexpr 控制流（无体内 if），
  特化在 **host 编排层**以两个示例文件完成（`attn_fwd.tila` /
  `attn_fwd_causal.tila`，黄金各自独立）——不是"最直白的写法"而是
  specialization 位置的精确描述；
- 教程的 STAGE 分程（`tl.range` start ≠ 0）是**性能机制**（因果约 2× flops
  差），语义等价单程 + 掩码即可——保留为未来优化项，不进本阶段；
- M 输出（log-softmax 统计，给 bwd 用）：可选。要与教程输出 M 对拍时加
  `log2`（评审焦点 #3，UNARY 表数据驱动一行）+ 附 M 缓冲 store——本阶段
  实现 `log2` 但 M 输出仅作一个演示用例（差分主比较仍是 o）。

## 3. v0.6b 实现分解（六块，均为 `v0.6-attention.md` 已有设计的落地）

A. **表面/前端**：`intrinsic.py` + `full`/`maximum`；frontend 放行 `*=`，
   识别 handoff（`acc = <局部名>`），三者归入 **AccumulatorUpdate** 语句
   类别（ReduceUpdate/ScaleUpdate/HandoffUpdate——普通 Assign 保持 SSA
   定义唯一含义）。**AccumulatorUpdate 与 StateRead 是正式 AST 语义类别
   （进主规范时入 `language-spec.md`/`ast.md` 文法与节点表），不是实现
   技巧**（评审 B-④）。
B. **checker**：R25（full：静态 shape、value 类别、dt ≠ bool）、R26
   （maximum：`'<'` 能力域、dtype 严格相等、shape ⊗）；**AccumulatorState
   状态机正式化**（评审 B-⑤/B-⑧）：

   ```
   AccumulatorState<S, D, LState>
   LState := Seed(value=V) | Materialized(L)

   ApplyUpdate 转移函数（checker 以单表实现，不在各检查点散落 if/else）：
     +=   Seed(V) × L                → Materialized(normalize(L))      （L7 语义）
     +=   Materialized(L) × L'       → Materialized(L)   require equiv(L, L')（E05）
     *=   Seed(0) × X                → Seed(0)           ——**mul-identity 特例**
                                                          （0·x = 0；不推广为
                                                          "任意常量种子可 *= "
                                                          的模糊规则，评审 B-⑨）
     *=   Seed(V≠0) × X              → E20 MulSeed
     *=   Materialized(L) × X        → Materialized(L)   （乘数 R-ST 读透明）
     handoff  Seed(V) × Lx           → Materialized(Lx)
     handoff  Materialized(L) × Lx   → Materialized(L)   require equiv(L, Lx)（E05）
   （StateRead 不改变状态；φ 的 back 边 = 最后一次 update 的结果）
   ```

   **seed 值规范化不变量**（评审 B-⑩）：`tila.full((…), 0, dt)` 与
   `tila.zeros((…), dt)` canonicalize 为**同一** `Seed(value=0)` 状态
   （checker 按指令的 value 判定，不是按名字）；`−∞` 种子 → `Seed(value=−∞)`
   ——"值属于指令、状态属于类型态"的分层（`TFull → Tile[.., Seed(shape)]`）。
   **StateRead 布局元变量 + 出口回填复检**（评审 14：α_acc、透明位不记约束、
   `α := L_exit` 后统一求解；迭代 1 种子值经 L7 语义相容）；**StateRead
   合法位 = 纯值表达式操作数**（评审 §26：store 实参/mask/coords 及传递
   依赖 → E20）；E20 新 subcode（HandoffForm / MulSeed / AccumRead 重新
   专用于逃逸位）。
C. **Seed 更名**：`Zeros(Σ)` → `Seed(Σ)`（term + dump 拼写与类型态语义；
   值语义留在 TZeros/TFull）；`matmul_loop` 黄金一次性再生（仅布局定义行，
   已入档）；v0.6b 内新增 `flash` 黄金用新拼写。
D. **TIR/后端**：`TFull`/`TMaximum` 两指令 + 两个 printer + interpreter
   （`np.full`/`np.maximum`；StateRead = `vals[phi]` 入口值——删限制而非
   加语义；ScaleUpdate/handoff 走既有 φ 链）；lowering 附核实项：
   `tl.full(-inf)` 已由 oracle 第三轮验证 ✓、`tl.maximum` 无提升 ✓。
E. **`log2`**：UNARY 表数据驱动一行（`UNARY = {exp, exp2, sqrt, log2}`
   → FLOAT 域；`infer_unary` 统一，无 per-op 逻辑）+ `np.log2`/`tl.log2`
   + 测试（评审焦点 #3/B-⑪）。
F. **语义测试矩阵**（`v0.6-attention.md` §8.5 全项 + 本规划补项 =
   进主规范的门）：
   - AccumulatorUpdate 状态机全转移（§3 B 表逐行；Seed→Materialized→
     equiv 锁定；ScaleUpdate Seed(0)→Seed(0)；非零种子 × → MulSeed；
     handoff 物化与 equiv）；
   - **handoff 负例补全**（评审 B-⑯）：`m = m1 + 0` / `m = cast(m1,…)` /
     `m = f(m1)` → HandoffForm；**`m = m`（自交接 no-op）→ HandoffForm**；
     **RHS 必须是当前迭代已定义且非累加器的局部**（`m = l`（另一累加器）
     → HandoffForm）；
   - **seed 规范化**：`full(…, 0, dt)` ≡ `zeros`（同状态断言）；`full(…,
     −∞, dt)` 的 `*=` → MulSeed；
   - StateRead 定型（α 求解正例 / 跨族读 E05 / 逃逸位矩阵）；
   - 复合重写（`l = l * alpha + s`）→ AccumForm；零迭代恒等式（N=0 出口
     = 种子）；多累加器（m/l/acc 三链 φ 互不干扰）；
   - **l 种子恒等式测试**（评审 B-⑰）：首块 α = 0 ⇒ `l₀=1` 与 `l₀=0`
     出口逐元素相等——Tila zeros 种子偏离 tutorial 的 justification 固化。

## 4. 验收

1. **门（评审 §25）**：§3 F 全绿 ⇒ v0.6b 进主规范（主文档同步此时完成）。
2. **验收分层（评审 B-⑱；出 bug 先定位层）**：


   tutorial 自身可能走不同数据路径/有限哨兵/累加顺序/平台特化——**不作
